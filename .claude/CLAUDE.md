## Non-negotiables
- **Read-only sources.** No adapter may expose a write method. The `ReadOnlyAdapter` Protocol has none.
- **Determinism is graded.** Same seed ⇒ byte-identical dataset, conflict set, and confidence vector.
  Never use `random` module-level functions, `uuid4()`, `datetime.now()`, `set` iteration order, or dict
  ordering that depends on insertion from an unordered source, anywhere on a graded path.
  Seed generator threads ONE `random.Random(seed)` instance. JSON always
  `json.dumps(obj, sort_keys=True, ensure_ascii=True, separators=(",",":"))`.
- **`recon/normalize.py` is THE shared spec (R23).** Both the seed generator and the detector import it.
  The generator imports NOTHING else from detector code.
- **LLM is rationale-text only.** It never detects conflicts, never computes confidence, never writes.
- **Holds before writes.** Proposals land `pending`/`sensitive_hold`. Enforcement is the two Postgres
  roles (`recon_writer` / `apply_writer`), not a code comment.
- **No PII.** Everything synthetic, from `recon.seed`. No real names/emails in fixtures, tests, or docs.
- **Docs are opt-in.** Never write process journals, changelogs, or per-action summaries into the repo.

## Toolchain
- Python 3.12 pinned via uv (`cd service && uv sync`). Run things as `uv run <cmd>` or activate `.venv`.
- Lint: `ruff check .` and `ruff format --check .` (line-length 100).
- Tests: `uv run pytest`. Coverage gate ≥80% on `recon/{adapters,normalize,er,invariants,confidence,reconciler,budget}`.
- Dashboard: `pnpm install`, `pnpm lint`, `pnpm test`, `pnpm test:a11y`.
- Postgres 16 + pgvector via `infra/docker-compose.yml` (image `pgvector/pgvector:pg16`), port **55432**
  on the host to avoid collisions. `DATABASE_URL` drives everything; never hardcode a DSN.
- Dataset profiles: `recon.seed --profile dev` (~5k records, all conflict classes present at scaled-down
  minimums) for the inner loop; `--profile full` (the graded ~100k Appendix-A dataset) for every gate,
  benchmark, and the committed `golden/` files. Same code path, same seed semantics — the profile only
  scales volumes.
